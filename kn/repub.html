Repub

ಕ್ರಾಪ್

ಪುಟದ ಅಂಚುಗಳನ್ನು ಹುಡುಕಿ ಸುತ್ತಲಿನ ಹಿನ್ನೆಲೆಯನ್ನು ಕತ್ತರಿಸುತ್ತದೆ.

ನೇರಗೊಳಿಸಿ

ಓರೆಯಾದ ಪುಟವನ್ನು ಪತ್ತೆಹಚ್ಚಿ ನೇರಗೊಳಿಸುತ್ತದೆ.

ಚಪ್ಪಟೆ ಮಾಡಿ

ಬೈಂಡಿಂಗ್ ಕಡೆಗೆ ಬಾಗಿದ ಪುಟಗಳಿಗೆ ಐಚ್ಛಿಕ ಡಿವಾರ್ಪಿಂಗ್. ಪ್ರಾಯೋಗಿಕ.

ಪಠ್ಯ ಓದಿ

ನೀವು ಆರಿಸುವ ಭಾಷೆಯಲ್ಲಿ Tesseract ಬಳಸಿ OCR.

ಹುಡುಕಬಹುದಾದ PDF

ಪುಟ ಚಿತ್ರಗಳ ಕೆಳಗೆ ಗುರುತಿಸಿದ ಪಠ್ಯ.

ಇತರ ಔಟ್‌ಪುಟ್‌ಗಳು

hOCR ಪಠ್ಯ ಫೈಲ್‌ಗಳು, ಥಂಬ್‌ನೇಲ್‌ಗಳು ಮತ್ತು ಇಂಟರ್ನೆಟ್ ಆರ್ಕೈವ್ ವಿನ್ಯಾಸದ ಫೋಲ್ಡರ್.

ಒಂದು ಆಜ್ಞೆ

ಫೋಲ್ಡರ್ ಅಥವಾ PDF ಒಳಗೆ, ಹುಡುಕಬಹುದಾದ PDF ಹೊರಗೆ. ಸ್ಕ್ಯಾನಿಂಗ್ ಯಂತ್ರದಲ್ಲಿ ಬ್ಯಾಚ್‌ಗಳಿಗೆ ಒಳ್ಳೆಯದು.

ವೆಬ್ ಆ್ಯಪ್

ಅಪ್‌ಲೋಡ್, ಪರಿಶೀಲನೆ, ಅಂತಿಮ

ಅಪ್‌ಲೋಡ್ ಮಾಡಿ, ಕೆಲಸ ನೋಡಿ, ಪುಟಗಳನ್ನು ಒಂದೊಂದಾಗಿ ಪರಿಶೀಲಿಸಿ, ಕ್ರಾಪ್ ಸರಿಪಡಿಸಿ, ನಂತರ ಅಂತಿಮಗೊಳಿಸಿ.

ಸ್ಕ್ರಿಪ್ಟ್ ಮಾಡಿ

API ಮತ್ತು Python ಕ್ಲೈಂಟ್

ಟೋಕನ್ ಬಳಸಿ ಕೆಲಸಗಳನ್ನು, CSV ಮೂಲಕ ಬ್ಯಾಚ್‌ಗಳನ್ನೂ ಕಳುಹಿಸಿ. ಫಲಿತಾಂಶಗಳು ತಾನಾಗಿ ಡೌನ್‌ಲೋಡ್ ಆಗುತ್ತವೆ.

ಪುಟವನ್ನು ಕ್ರಾಪ್ ಮಾಡುವುದು

ಸ್ಕ್ಯಾನ್‌ಗಳಲ್ಲಿ ಸುತ್ತಲೂ ಅಂಚು ಇರುತ್ತದೆ: ಕ್ರೇಡಲ್, ಮೇಜು, ಕೈ. Repub ಪುಟದ ಬಾಹ್ಯರೇಖೆಯನ್ನು ಹುಡುಕಿ ಅಲ್ಲಿಗೇ ಕತ್ತರಿಸುತ್ತದೆ, ಆದ್ದರಿಂದ ಪುಸ್ತಕದ ಎಲ್ಲ ಪುಟಗಳೂ ಒಂದೇ ಆಕಾರದಲ್ಲಿರುತ್ತವೆ.

  • ಸ್ವಿಚ್: -c ಅಥವಾ --crop
  • ಚಿತ್ರದ ಅತಿ ದೊಡ್ಡ ಬಾಹ್ಯರೇಖೆಗಳನ್ನು ನೋಡುತ್ತದೆ. --maxcontours ಎಷ್ಟು ಎಂದು ಹೇಳುತ್ತದೆ (ಡಿಫಾಲ್ಟ್ 5)
  • ವೆಬ್ ಆ್ಯಪ್‌ನಲ್ಲಿ ಯಾವುದೇ ಪುಟದ ಕ್ರಾಪ್ ಅಂಚುಗಳನ್ನು ಕೈಯಿಂದ ಸರಿಸಬಹುದು
python process_raw.py -i scans -o out --crop

ಪುಟವನ್ನು ನೇರಗೊಳಿಸುವುದು

ಪುಟ ಕೆಲವು ಡಿಗ್ರಿ ಓರೆಯಾದರೆ ಪಠ್ಯದ ಸಾಲುಗಳು ಇಳಿಜಾರಾಗುತ್ತವೆ, ಇಳಿಜಾರಾದ ಸಾಲುಗಳನ್ನು OCR ಸರಿಯಾಗಿ ಓದುವುದಿಲ್ಲ. Repub ಓರೆಯನ್ನು ಅಳೆದು ಪುಟವನ್ನು ನೇರಗೊಳಿಸುತ್ತದೆ.

  • ಸ್ವಿಚ್: -D ಅಥವಾ --deskew
  • ಓರೆಯನ್ನು ಲಂಬ ಗೆರೆಗಳಿಂದ, ಅಡ್ಡ ಗೆರೆಗಳಿಂದ ಅಥವಾ ಇಡೀ ಪುಟದಿಂದ ಅಳೆಯಬಹುದು
  • OCR ಗೂ ಮೊದಲು ನಡೆಯುತ್ತದೆ, ಹಾಗಾಗಿ ಪಠ್ಯ ನೇರ ಪುಟದಿಂದ ಓದಲಾಗುತ್ತದೆ
python process_raw.py -i scans -o out --crop --deskew

ಬಾಗಿದ ಪುಟಗಳನ್ನು ಚಪ್ಪಟೆ ಮಾಡುವುದು

ದಪ್ಪ ಪುಸ್ತಕದ ಪುಟಗಳು ಬೈಂಡಿಂಗ್ ಕಡೆಗೆ ಬಾಗುತ್ತವೆ. ಡಿವಾರ್ಪಿಂಗ್ ಆ ಬಾಗನ್ನು ಚಪ್ಪಟೆ ಮಾಡಿ ಪಠ್ಯದ ಸಾಲುಗಳನ್ನು ನೇರ ಮಾಡುತ್ತದೆ.

  • ಸ್ವಿಚ್: -w ಅಥವಾ --dewarp
  • ಮುಕ್ತ ಮೂಲದ page_dewarp ಲೈಬ್ರರಿ ಬಳಸುತ್ತದೆ
  • ಪ್ರಾಯೋಗಿಕ: ಇಡೀ ಬ್ಯಾಚ್ ಮೊದಲು ನಿಮ್ಮ ಪುಸ್ತಕಗಳಲ್ಲಿ ಫಲಿತಾಂಶ ಪರಿಶೀಲಿಸಿ
python process_raw.py -i scans -o out --dewarp

ಪಠ್ಯ ಓದುವುದು

Tesseract ಪ್ರತಿ ಪುಟವನ್ನು ಓದಿ ಪದಗಳನ್ನೂ ಪ್ರತಿ ಪದ ಪುಟದಲ್ಲಿ ಎಲ್ಲಿದೆ ಎಂಬುದನ್ನೂ ಕೊಡುತ್ತದೆ. Tesseract ಗೆ ತರಬೇತಿ ನೀಡಿರುವ ಯಾವುದೇ ಭಾಷೆಯಲ್ಲಿ Repub ಕೆಲಸ ಮಾಡುತ್ತದೆ.

  • ಸ್ವಿಚ್: -t ಅಥವಾ --ocr. ಭಾಷೆ: -L, ಉದಾ. kan ಅಥವಾ eng+hin
  • ನಿಮಗೆ ಬೇಕಾದ ಭಾಷಾ ಪ್ಯಾಕ್‌ಗಳನ್ನು ಇನ್‌ಸ್ಟಾಲ್ ಮಾಡಿ; tesseract-ocr-all ಎಲ್ಲವನ್ನೂ ಹೊಂದಿದೆ
  • ಪದಗಳ ಸ್ಥಾನವನ್ನು hOCR ಔಟ್‌ಪುಟ್‌ನಲ್ಲಿ ಉಳಿಸಲಾಗುತ್ತದೆ
python process_raw.py -i scans -o out --ocr -L kan

ಹೊರಗೆ ಏನು ಬರುತ್ತದೆ

ಪ್ರತಿ ಪುಸ್ತಕವು ಗ್ರಂಥಾಲಯಕ್ಕೆ ಬೇಕಾದ ರೂಪಗಳಲ್ಲಿ Repub ನಿಂದ ಹೊರಬರುತ್ತದೆ.

  • ಹುಡುಕಬಹುದಾದ PDF: ಪುಟ ಚಿತ್ರಗಳ ಕೆಳಗೆ ಪಠ್ಯ
  • ಪ್ರತಿ ಪುಟಕ್ಕೆ hOCR ಫೈಲ್‌ಗಳು ಮತ್ತು ಥಂಬ್‌ನೇಲ್‌ಗಳು
  • -A ಇಂಟರ್ನೆಟ್ ಆರ್ಕೈವ್ ನಿರೀಕ್ಷಿಸುವ ವಿನ್ಯಾಸದಲ್ಲಿ ಫೋಲ್ಡರ್ ಬರೆಯುತ್ತದೆ
  • -r ಚಿತ್ರಗಳನ್ನು ಚಿಕ್ಕದಾಗಿಸುತ್ತದೆ, ಫೈಲ್ ಗಾತ್ರ ಕಡಿಮೆ ಆಗುತ್ತದೆ
python process_raw.py -I book.pdf -O book-searchable.pdf --ocr
python process_raw.py -i scans -A ia_output
ಮೂರು ವಿಧಗಳಲ್ಲಿ ನಡೆಸಿ
# ಸ್ಕ್ಯಾನ್‌ಗಳ ಫೋಲ್ಡರ್
python process_raw.py -i scans -o out --crop --deskew --ocr -L kan

# ಒಂದು PDF
python process_raw.py -I book.pdf -O book-searchable.pdf --crop --deskew --ocr

# ಇಂಟರ್ನೆಟ್ ಆರ್ಕೈವ್‌ಗಾಗಿ
python process_raw.py -i scans -A ia_output
ಸಾಮಾನ್ಯ ಸ್ವಿಚ್‌ಗಳು
  • -i ಸ್ಕ್ಯಾನ್ ಚಿತ್ರಗಳ ಫೋಲ್ಡರ್
  • -I ಸಂಸ್ಕರಿಸಬೇಕಾದ PDF
  • -o / -O ಔಟ್‌ಪುಟ್ ಫೋಲ್ಡರ್ / ಔಟ್‌ಪುಟ್ PDF
  • -c ಪುಟದ ಅಂಚುಗಳನ್ನು ಕ್ರಾಪ್ ಮಾಡಿ
  • -D ಓರೆಯಾದ ಪುಟಗಳನ್ನು ನೇರಗೊಳಿಸಿ
  • -t OCR ನಡೆಸಿ, ಹುಡುಕಬಹುದಾದ PDF ಮಾಡಿ
  • -L OCR ಭಾಷೆ, ಡಿಫಾಲ್ಟ್ eng
  • -w ಬಾಗಿದ ಪುಟಗಳನ್ನು ಚಪ್ಪಟೆ ಮಾಡಿ (ಪ್ರಾಯೋಗಿಕ)
  • -r ಚಿತ್ರಗಳ ಗಾತ್ರ ಬದಲಿಸಿ, ಉದಾ. 0.5
  • -A ಇಂಟರ್ನೆಟ್ ಆರ್ಕೈವ್ ವಿನ್ಯಾಸ
ಹಂತ 1

ಅಪ್‌ಲೋಡ್

PDF ಅಥವಾ ಪುಟ ಚಿತ್ರಗಳ ZIP ಅನ್ನು ನಿಮಗೆ ಬೇಕಾದ ಆಯ್ಕೆಗಳೊಂದಿಗೆ ಕಳುಹಿಸಿ.

ಹಂತ 2

ಸಂಸ್ಕರಣೆ

ಕೆಲಸ ಹಿನ್ನೆಲೆಯಲ್ಲಿ ನಡೆಯುತ್ತದೆ. ಅದರ ಸ್ಥಿತಿ ಕೆಲಸದ ಪುಟದಲ್ಲಿ ಕಾಣುತ್ತದೆ.

ಹಂತ 3

ಪರಿಶೀಲನೆ

ಪುಟಗಳನ್ನು ಒಂದೊಂದಾಗಿ ತೆರೆದು, ಸ್ವಯಂಚಾಲಿತ ಕ್ರಾಪ್ ತಪ್ಪಾಗಿರುವಲ್ಲಿ ಸರಿಪಡಿಸಿ.

ಹಂತ 4

ಅಂತಿಮಗೊಳಿಸಿ

ಒಪ್ಪಿಗೆ ನೀಡಿ, Repub ಅಂತಿಮ PDF, hOCR ಮತ್ತು ಥಂಬ್‌ನೇಲ್‌ಗಳನ್ನು ಡೌನ್‌ಲೋಡ್‌ಗಾಗಿ ಸಿದ್ಧಪಡಿಸುತ್ತದೆ.

ಕೆಲಸಗಳು

ಒಂದೇ ಬಾರಿ ಹಲವು ದಾಖಲೆಗಳು

ಕೆಲಸಗಳನ್ನು ಅಪ್‌ಲೋಡ್ ಮಾಡಿ, ಗಮನಿಸಿ, ನಿರ್ವಹಿಸಿ, ಒಂದು ಬಾರಿಗೆ ಹಲವು ದಾಖಲೆಗಳು.

ಖಾತೆಗಳು

ಬಳಕೆದಾರರು ಮತ್ತು ನಿರ್ವಾಹಕ ಪ್ಯಾನೆಲ್

ಪ್ರತಿಯೊಬ್ಬರಿಗೂ ಸೈನ್-ಇನ್, ಬಳಕೆದಾರರು ಮತ್ತು ಸೆಟ್ಟಿಂಗ್‌ಗಳಿಗೆ ನಿರ್ವಾಹಕ ಪುಟ.

API

REST API ಮತ್ತು Python ಕ್ಲೈಂಟ್

ಟೋಕನ್ ಸೈನ್-ಇನ್, ಪ್ರತಿ ಫೈಲ್‌ಗೆ ಭಾಷೆಯೊಂದಿಗೆ CSV ಯಿಂದ ಬ್ಯಾಚ್ ಕಳುಹಿಸುವುದು, ಸಮಾಂತರವಾಗಿ ಓಡುತ್ತದೆ.

ಕಮಾಂಡ್ ಲೈನ್ ಮಾತ್ರ

Python, OpenCV, Tesseract

Python 3.8 ಅಥವಾ ನಂತರದ್ದು, OpenCV, Tesseract ಮತ್ತು Poppler. ಫೋಲ್ಡರ್ ಅಥವಾ PDF ಸಂಸ್ಕರಿಸಲು ಇಷ್ಟು ಸಾಕು.

ವೆಬ್ ಆ್ಯಪ್

Django, ಡೇಟಾಬೇಸ್ ಮತ್ತು ಕ್ಯೂ

ಪ್ರಯತ್ನಿಸಲು SQLite ಜೊತೆ Django 5.2, ನಿಜವಾದ ಬಳಕೆಗೆ PostgreSQL. ಹಿನ್ನೆಲೆ ಕೆಲಸಗಳು Celery ಮತ್ತು Redis ಮೇಲೆ ನಡೆಯುತ್ತವೆ.

ಪರವಾನಗಿ

MIT

ಬಳಸಲು, ಬದಲಿಸಲು ಮತ್ತು ಹಂಚಲು ಉಚಿತ. ಮೂಲ ಕೋಡ್, ಸಮಸ್ಯೆಗಳು ಮತ್ತು ಪೂರ್ಣ README GitHub ನಲ್ಲಿವೆ.

# ಪಡೆಯಿರಿ
git clone https://github.com/ServantsOfKnowledge/repub.git
cd repub
pip install -r requirements.txt

# ಸಿಸ್ಟಮ್ ಪ್ಯಾಕೇಜ್‌ಗಳು (Ubuntu ಅಥವಾ Debian; Mac ನಲ್ಲಿ: brew install tesseract poppler)
sudo apt-get install tesseract-ocr tesseract-ocr-all poppler-utils

# ಕಮಾಂಡ್ ಲೈನ್
cd repub && python process_raw.py -i scans -o out --crop --deskew --ocr

# ವೆಬ್ ಆ್ಯಪ್
cd repubui && cp .env.example .env
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver

ಕೋಡ್ ಬದಲಾದಂತೆ ವಿವರಗಳು ಬದಲಾಗುತ್ತವೆ, ಆದ್ದರಿಂದ README ಅಧಿಕೃತ ಆಧಾರ. Python ಕ್ಲೈಂಟ್: API ಕ್ಲೈಂಟ್ ಮಾರ್ಗದರ್ಶಿ.
