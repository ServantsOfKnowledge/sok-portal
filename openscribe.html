Capture here, process there

OpenScribe captures and packages. Repub crops, straightens and reads the text.

Describe the book

Start with the item: identifier, title, creator, language, collection set and page progression. Collection sets live in one editable file.

  • A web page, served on the scanning machine
  • Data is kept in a local folder you choose
  • Simulated cameras by default; switch to real cameras in the page header
python -m openscribe

Shoot spreads and inserts

One key fires the left and right cameras together. The first spread is typed Color Card and Cover for you. A foldout or loose sheet uses the insert camera.

  • Default resolution: 360 ppi
  • Default rotation: left -90, right 90, insert 90, changeable for each page
  • Cameras are matched to left, right and insert by their USB port
Space   shoot a spread (left and right together)
I       shoot an insert (the next leaf number)

Review and retake

Select a page to change its type, turn it or shoot it again. The Pages tab lists every page with a small preview. Hover any shot for a magnifier.

  • Page types: Normal, Cover, Title, Index, Color Card, Foldout, Map, Insert
  • The magnifier loads the untouched camera image, so sharpness and text can be checked
  • Unselected pages stay Normal
R       retake the selected page
1 to 8   set the page type
Z       magnifier at 100% or 200%

Check and package

Finishing a book closes it with a Cover and Color Card, then the quality check runs. A clean book is packaged: JPEG to JP2, page data, metadata and checksums.

  • The first page must be a Color Card, with no gaps, and the last spread must have one
  • Camera originals and retakes are kept in their own folders
  • Every step is logged with the same event names the scanner uses
<identifier>_preimage.zip
<identifier>_meta.xml
<identifier>_checksums.json

Queue for Repub

The finished package goes to Repub, which crops, straightens and reads the text.

  • Today it is copied to an outbox folder
  • Next: a client built on Repub's own API
  • The same crop and straighten code is shared with Repub
data/outbox/<identifier>/
What the package holds
<identifier>_preimage.zip
  0000.jp2 ... NNNN.jp2
  scandata.json

<identifier>_meta.xml

<identifier>_checksums.json
Details
  • Pages as JP2 images, in order, unrotated
  • scandata.json: resolution, page type, rotation and capture time for every page
  • Item details from the form, written to a metadata file
  • Checksums: md5, sha1, crc32 and sha256 for the zip and each file in it
  • Laid out to match a sample preimage from the Scribe3 stations
Try it

Python and one command

Install the requirements and start the app. It opens at a local address with simulated cameras.

Real cameras

gphoto2 and a config file

Install gphoto2, find each camera's USB port and set the ports in openscribe.json. Set the cameras to JPEG only.

Licence

MIT

Free to use, change and share. The full documentation is on GitHub.

# try it with simulated cameras
pip install -r requirements.txt
python -m openscribe

# or with Docker
docker compose up --build -d

# real cameras (not yet tested on hardware)
sudo apt install gphoto2
gphoto2 --auto-detect
cp openscribe.example.json openscribe.json

Details change as the code does, so the documentation is the reference.
