Crop the page

Scans come with a border: the cradle, the table, a hand. Repub finds the outline of the page and trims to it, so every page in a book ends up the same shape.

  • Switch: -c or --crop
  • It looks at the biggest outlines in the image. --maxcontours sets how many (default 5)
  • In the web app you can move the crop edges of any page by hand
python process_raw.py -i scans -o out --crop

Straighten the page

A page a few degrees off makes lines of text slope, and OCR reads sloped lines badly. Repub measures the tilt and turns the page level.

  • Switch: -D or --deskew
  • The tilt can be measured from vertical lines, horizontal lines or the whole page
  • Runs before OCR, so the text is read from a level page
python process_raw.py -i scans -o out --crop --deskew

Flatten curved pages

Pages of a thick book curve towards the spine. Dewarping flattens the curve so lines of text run straight.

  • Switch: -w or --dewarp
  • Uses the open-source page_dewarp library
  • Experimental: check the result on your own books before a whole batch
python process_raw.py -i scans -o out --dewarp

Read the text

Tesseract reads each page and returns the words and where each one sits on the page. Repub works in any language Tesseract has been trained for.

  • Switch: -t or --ocr. Language: -L, for example kan or eng+hin
  • Install the language packs you need; tesseract-ocr-all has them all
  • Word positions are kept in the hOCR output
python process_raw.py -i scans -o out --ocr -L kan

What comes out

Each book leaves Repub in the forms a library needs.

  • A searchable PDF: the page images with the text underneath
  • hOCR files and thumbnails for every page
  • -A writes a folder in the layout the Internet Archive expects
  • -r scales images down, for smaller files
python process_raw.py -I book.pdf -O book-searchable.pdf --ocr
python process_raw.py -i scans -A ia_output
Three ways to run it
# a folder of scans
python process_raw.py -i scans -o out --crop --deskew --ocr -L kan

# a PDF
python process_raw.py -I book.pdf -O book-searchable.pdf --crop --deskew --ocr

# for the Internet Archive
python process_raw.py -i scans -A ia_output
Common switches
  • -i folder of scanned images
  • -I a PDF to process
  • -o / -O output folder / output PDF
  • -c crop the page edges
  • -D straighten tilted pages
  • -t run OCR, make a searchable PDF
  • -L OCR language, default eng
  • -w flatten curved pages (experimental)
  • -r scale images, for example 0.5
  • -A Internet Archive layout
Step 1

Upload

Send a PDF or a ZIP of page images, with the options you want.

Step 2

Process

The job runs in the background. Its status shows on the job page.

Step 3

Review

Open pages one by one and fix a crop where the automatic result is off.

Step 4

Finalise

Approve, and Repub builds the final PDF, hOCR and thumbnails to download.

Jobs

Many documents at once

Accounts

Users and an admin panel

Sign-in for each person, and an admin page for users and settings.

API

REST API and Python client

Token sign-in, batch submit from a CSV with a language for each file, runs in parallel.

Command line only

Python, OpenCV, Tesseract

Python 3.8 or later, OpenCV, Tesseract and Poppler. Enough to process a folder or a PDF.

Web app

Django, a database and a queue

Django 5.2 with SQLite to try it, PostgreSQL for real use. Background jobs run on Celery and Redis.

pip install -r requirements.txt

sudo apt-get install tesseract-ocr tesseract-ocr-all poppler-utils

# command line
cd repub && python process_raw.py -i scans -o out --crop --deskew --ocr

# web app
cd repubui && cp .env.example .env
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
